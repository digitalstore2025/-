## 1. نظرة عامة | Overview

### 1.1 الغرض | Purpose

هذه الوثيقة تُثبت أن نظام التوثيق البصري الإنساني (HVS) مصمم ومُنفذ للامتثال الكامل مع:

This document certifies that the Humanitarian Visual System (HVS) is designed and implemented in full compliance with:

- القانون الدولي الإنساني (IHL)
- المعايير الإنسانية الأساسية (CHS)
- معايير SPHERE
- قواعد السلوك للحركة الدولية للصليب الأحمر والهلال الأحمر
- لوائح حماية البيانات (GDPR حيثما ينطبق)

### 1.2 النطاق | Scope

| العنصر | النطاق |
|--------|-------|
| المنظمة | الهلال الأحمر التركي |
| المنطقة | غزة وأي منطقة عمليات |
| التطبيق | جميع التوثيق البصري |
| الفترة | مستمر |

