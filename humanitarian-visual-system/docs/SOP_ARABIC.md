## 1. القيود المطلقة

### ⛔ غير قابلة للتفاوض

| # | القيد | الإجراء |
|---|-------|---------|
| 1 | لا تصوير أو نشر يعرّض أي مستفيد للخطر | رفض فوري |
| 2 | لا إظهار وجوه في حالات النزوح، الصدمة، أو الأطفال دون موافقة | رفض أو تمويه |
| 3 | لا تصوير جثامين مكشوفة أو إصابات مروّعة | رفض فوري |
| 4 | لا تحديد مواقع حساسة (إحداثيات – معالم – توقيتات) | حذف البيانات |
| 5 | لا مؤثرات بصرية أو صوتية درامية | رفض |
| 6 | أي مادة تخالف الأخلاقيات تُستبعد تلقائيًا | استبعاد تلقائي |

## 2. إعدادات التصوير

### الإعدادات الإلزامية

```
الوضع: يدوي + ISO تلقائي
الحد الأقصى لـ ISO: 6400
سرعة الغالق: ≥ 1/100
فتحة العدسة: f/2.8 – f/4
توازن الأبيض: تلقائي
ملف الصورة: محايد / مسطح

الصوت:
- معدل العينة: 48kHz
- عمق البت: 24bit
- الصيغة: WAV
```

### إعدادات المشاهد

| المشهد | ISO | الغالق | الفتحة |
|--------|-----|--------|--------|
| خارجي - نهار | 100-400 | 1/250 | f/4 |
| خارجي - غائم | 400-800 | 1/125 | f/2.8 |
| داخلي - إضاءة طبيعية | 800-3200 | 1/100 | f/2.8 |
| داخلي - إضاءة منخفضة | 3200-6400 | 1/60 | f/2.8 |

## 3. منطق التصوير

### تسلسل اللقطات لكل مشهد

```
1. لقطة تأسيسية (Wide – السياق)
   ↓
2. لقطة فعل (المساعدة قيد التنفيذ)
   ↓
3. لقطة تفصيلية (الأيدي / الحركة / التفاعل)
   ↓
الخروج الفوري إذا زاد الخطر
```

### ❌ الأفعال الممنوعة

- إعادة تمثيل
- طلب تفاعل عاطفي
- توجيه المستفيد
- تصوير وجه بدون موافقة موثقة

## 4. إدارة الملفات

### هيكل المجلدات

```
/Gaza_Mission/
├── RAW/
│   ├── Day_01/
│   ├── Day_02/
│   └── ...
├── AUDIO/
├── SELECTS/
├── EDIT/
├── FINAL/
└── LOGS/
```

### القواعد

1. **تقسيم يومي:** كل يوم في مجلد منفصل
2. **بطاقات متعددة:** استخدام أكثر من كارت لتقليل الخسارة
3. **نسخ احتياطي فوري:** عند توفر اتصال أو تخزين إضافي
4. **تسمية موحدة:** `TRC_Gaza_YYYYMMDD_TYPE_###`

### أنواع الملفات

| الرمز | النوع |
|-------|-------|
| AID | توزيع مساعدات |
| MED | خدمات طبية |
| SHL | إيواء |
| WSH | مياه وصرف صحي |
| PSS | دعم نفسي |
| GEN | عام |

## 5. المراجعة الأخلاقية

### الفحص الآلي

```
لكل مادة:
  إذا (وجه_مرئي AND لا_موافقة) → رفض
  إذا (موقع_حساس == صحيح) → رفض
  إذا (محتوى_صادم == صحيح) → رفض
  وإلا → موافقة
```

### قائمة الفحص

- [ ] لا وجوه مكشوفة بدون موافقة
- [ ] لا أطفال قابلين للتعريف
- [ ] لا إحداثيات GPS
- [ ] لا معالم حساسة
- [ ] لا محتوى صادم
- [ ] لا مؤثرات درامية

### حالات الموافقة

| الحالة | الرمز | الإجراء التالي |
|--------|-------|----------------|
| موافق | ✓ | جاهز للمونتاج |
| قيد المراجعة | ⏳ | يحتاج مراجعة بشرية |
| مرفوض | ✗ | لا يستخدم |
| يحتاج تمويه | ⚠️ | تمويه ثم مراجعة |

## 6. المونتاج

### القواعد المسموحة

| الإجراء | ملاحظات |
|---------|---------|
| قص | بدون تلاعب |
| تصحيح ألوان | تصحيح فقط، ليس تدرج سينمائي |
| تنظيف صوت | تقليل ضوضاء فقط |

### ⛔ الممنوعات

| الإجراء | السبب |
|---------|-------|
| حركة بطيئة للمآسي | درامي غير مقبول |
| LUTs سينمائية | تحريف للواقع |
| موسيقى درامية | استعطاف |
| مؤثرات صوتية | تلاعب عاطفي |

### مواصفات التصدير

```
الفيديو:
- الترميز: H.264 / H.265
- الدقة: 1920x1080
- المدة: 30-45 ثانية (إلا إذا تطلب التقرير أكثر)

الصوت:
- الترميز: AAC
- معدل البت: 320 kbps
```

## 8. النشر الآمن

### البروتوكول

```
إذا (مستوى_الخطر == عالي):
    تأخير النشر
وإلا:
    النشر عبر القنوات الرسمية فقط
```

### القواعد

| ⛔ ممنوع | ✓ مسموح |
|---------|---------|
| نشر مباشر من الميدان | نشر من المقر بعد المراجعة |
| مشاركة ملفات خام | مشاركة ملفات معالجة |
| Metadata حساسة | ملفات منظفة من GPS |
| وسم الموقع الدقيق | الموقع العام فقط |
