## 1. مقدمة | Introduction

### ما هو هذا النظام؟ | What is this system?

نظام التوثيق البصري الإنساني هو أداة متكاملة صُممت خصيصاً للعمل في بيئات النزاع، تضمن:

- ✅ حماية المستفيدين من أي ضرر
- ✅ الامتثال للقانون الدولي الإنساني
- ✅ توثيق أخلاقي للعمليات الإنسانية
- ✅ سجل قانوني قابل للتدقيق

### لمن هذا الدليل؟ | Who is this guide for?

| الفئة | المستوى |
|-------|---------|
| المصور الميداني | أساسي |
| مسؤول الإعلام | متقدم |
| المراجع الأخلاقي | متقدم |
| مدير البعثة | إشرافي |

## 2. المبادئ الأساسية | Core Principles

### 🔴 القواعد غير القابلة للتفاوض | Non-Negotiable Rules

هذه القواعد **لا يمكن تجاوزها** تحت أي ظرف:

```
┌─────────────────────────────────────────────────────────────────┐
│  ❌ 1. لا تصوير يعرّض المستفيد للخطر                            │
│       No photography that endangers beneficiaries               │
├─────────────────────────────────────────────────────────────────┤
│  ❌ 2. لا وجوه بدون موافقة موثقة                                │
│       No faces without documented consent                       │
├─────────────────────────────────────────────────────────────────┤
│  ❌ 3. لا جثامين أو إصابات صادمة                                │
│       No bodies or graphic injuries                             │
├─────────────────────────────────────────────────────────────────┤
│  ❌ 4. لا تحديد مواقع حساسة                                     │
│       No sensitive location identification                      │
├─────────────────────────────────────────────────────────────────┤
│  ❌ 5. لا مؤثرات درامية أو استعطافية                            │
│       No dramatic or emotional manipulation                     │
├─────────────────────────────────────────────────────────────────┤
│  ❌ 6. استبعاد تلقائي لأي مادة مخالفة                           │
│       Automatic exclusion of any non-compliant material         │
└─────────────────────────────────────────────────────────────────┘
```

### ✅ ما المسموح؟ | What is allowed?

- توثيق العمليات الإنسانية (توزيع مساعدات، علاج طبي)
- صور الفرق العاملة (بموافقتهم)
- مشاهد عامة للوضع الإنساني (بدون تحديد دقيق)
- قصص نجاح (بموافقة المستفيد)

## 3. التثبيت والإعداد | Installation

### الخطوة 1: التثبيت | Step 1: Installation

```bash
# على الحاسوب الميداني
pip install humanitarian-visual

# أو من المصدر
cd humanitarian-visual-system
pip install -e .
```

### الخطوة 2: التهيئة | Step 2: Initialize

```bash
hv init --name "Gaza Mission Day 01"
```

سيُنشئ النظام الهيكل التالي:
```
Gaza_Mission/
├── RAW/           ← الملفات الخام
├── IMPORTED/      ← المستوردة
├── REVIEW/        ← قيد المراجعة
├── APPROVED/      ← الموافق عليها
├── REJECTED/      ← المرفوضة
├── REDACTED/      ← المعدّلة (طمس)
├── ARCHIVE/       ← الأرشيف
├── EXPORT/        ← للتصدير
├── LOGS/          ← السجلات
└── CAPTIONS/      ← التعليقات
```

### الخطوة 3: التحقق | Step 3: Verify

```bash
hv status
```

يجب أن ترى:
```
✓ System initialized
✓ All directories created
✓ Ethical gate active
```

## 4. سير العمل الميداني | Field Workflow

### المخطط العام | Overview

```
     📷 التقاط                    🔒 النظام يحمي
        ↓                              ↓
┌──────────────┐              ┌──────────────────┐
│   CAPTURE    │              │  AUTO-PROTECT    │
│   التقاط     │──────────────│  حماية تلقائية   │
└──────────────┘              └──────────────────┘
        ↓                              ↓
┌──────────────┐              ┌──────────────────┐
│   IMPORT     │              │  STRIP METADATA  │
│   استيراد    │──────────────│  إزالة البيانات  │
└──────────────┘              └──────────────────┘
        ↓                              ↓
┌──────────────┐              ┌──────────────────┐
│   REVIEW     │              │  DETECT FACES    │
│   مراجعة     │──────────────│  كشف الوجوه     │
└──────────────┘              └──────────────────┘
        ↓                              ↓
   ┌────┴────┐                ┌──────────────────┐
   ↓         ↓                │  AUTO-BLUR       │
✅ APPROVE  ❌ REJECT          │  طمس تلقائي     │
   ↓                          └──────────────────┘
┌──────────────┐
│   CAPTION    │
│   تعليق      │
└──────────────┘
        ↓
┌──────────────┐
│   ARCHIVE    │
│   أرشفة      │
└──────────────┘
```

### الأوامر الأساسية | Basic Commands

| الأمر | الوظيفة | مثال |
|-------|---------|------|
| `hv import` | استيراد ملف | `hv import IMG_001.jpg` |
| `hv review` | مراجعة ملف | `hv review IMG_001.jpg` |
| `hv blur` | طمس الوجوه | `hv blur IMG_001.jpg` |
| `hv approve` | الموافقة | `hv approve IMG_001.jpg` |
| `hv reject` | الرفض | `hv reject IMG_001.jpg -r "وجه طفل"` |
| `hv caption` | إضافة تعليق | `hv caption IMG_001.jpg` |
| `hv archive` | الأرشفة | `hv archive` |
| `hv dashboard` | الواجهة | `hv dashboard` |

## 5. التدريب العملي | Hands-on Training

### 🎯 تمرين 1: الاستيراد الأساسي | Exercise 1: Basic Import

**الهدف:** استيراد صورة وفحصها أخلاقياً

```bash
# 1. تهيئة بعثة تدريبية
hv init --name "Training Mission"

# 2. تشغيل وضع المحاكاة
hv simulate --scenario basic_import

# 3. استيراد الصورة التدريبية
hv import training_photo_01.jpg

# 4. مراجعة الصورة
hv review training_photo_01.jpg
```

**المتوقع:**
- النظام يكتشف وجهاً
- يطلب إما طمس أو موافقة موثقة

---

### 🎯 تمرين 2: طمس الوجوه | Exercise 2: Face Blur

**الهدف:** تطبيق طمس الوجوه على صورة

```bash
# 1. تشغيل السيناريو
hv simulate --scenario face_blur

# 2. الصورة تحتوي 3 وجوه بدون موافقة
hv blur simulated_faces.jpg

# 3. التحقق
hv review simulated_faces.jpg
```

**المتوقع:**
- طمس 3 وجوه
- الانتقال للموافقة ممكن

---

### 🎯 تمرين 3: رفض محتوى | Exercise 3: Content Rejection

**الهدف:** التعرف على المحتوى المرفوض

```bash
# تشغيل سيناريو المحتوى الصادم
hv simulate --scenario graphic_content

# محاولة استيراد (سيُرفض تلقائياً)
hv import simulated_graphic.jpg
```

**المتوقع:**
```
❌ REJECTED: Graphic content detected
   المحتوى الصادم مكتشف - تم الرفض التلقائي
```

---

### 🎯 تمرين 4: التعليق التوضيحي | Exercise 4: Captioning

**الهدف:** كتابة تعليق أخلاقي صحيح

## 6. حالات خاصة | Special Cases

### الحالة 1: موافقة موثقة | Documented Consent

إذا حصلت على موافقة خطية من الشخص:

```bash
hv approve photo.jpg --consent
```

**متطلبات الموافقة:**
- توقيع خطي أو شفهي مسجل
- شرح واضح لكيفية الاستخدام
- حق السحب في أي وقت

---

### الحالة 2: حالة طوارئ | Emergency Situation

في حالات الطوارئ القصوى، يمكن تجاوز بعض الخطوات:

```bash
hv import photo.jpg --emergency
```

**⚠️ تحذير:** هذا لا يتجاوز القواعد الأخلاقية، فقط يسرّع العملية.

---

### الحالة 3: أرشفة قانونية | Legal Archive

للأرشفة القانونية (غير منشورة):

```bash
hv archive --legal-only
```

هذه الملفات تُحفظ للتوثيق القانوني فقط، لا للنشر.

## 7. الأسئلة الشائعة | FAQ

### س: ماذا لو التقطت صورة بالخطأ تحتوي محتوى صادم؟

**ج:** النظام سيرفضها تلقائياً عند الاستيراد. لا داعي للقلق.

---

### س: هل يمكنني نشر صورة بدون مرورها بالنظام؟

**ج:** **لا.** جميع الصور يجب أن تمر بالنظام. هذا حماية قانونية لك وللمنظمة.

---

### س: ماذا لو لم يكتشف النظام وجهاً يجب طمسه؟

**ج:** استخدم الطمس اليدوي:
```bash
hv blur photo.jpg --manual
```
ثم حدد المنطقة في الواجهة.

---

### س: كيف أتحقق من سلامة السجلات؟

**ج:**
```bash
hv verify-logs
```
النظام يستخدم سلسلة تجزئة (hash chain) للتأكد من عدم التلاعب.

---

### س: هل يعمل النظام بدون إنترنت؟

**ج:** **نعم.** النظام مصمم للعمل الميداني بدون أي اتصال.

## 8. اختبار الكفاءة | Competency Test

### الجزء النظري | Theory (10 أسئلة)

1. اذكر ثلاثة من القواعد غير القابلة للتفاوض.
2. ما الفرق بين APPROVED و ARCHIVED؟
3. متى يُفعّل طمس الوجوه تلقائياً؟
4. ما المعلومات التي يحذفها النظام من الصور؟
5. ما المصطلحات الممنوعة في التعليقات؟
6. كيف توثّق الموافقة على إظهار وجه؟
7. ما الغرض من سلسلة التجزئة في السجلات؟
8. متى يمكن استخدام وضع الطوارئ؟
9. ما الفرق بين الأرشيف العادي والقانوني؟
10. لماذا نستخدم مواقع عامة فقط؟

---

### الجزء العملي | Practical (5 مهام)

```bash
# تشغيل اختبار الكفاءة
hv simulate --test competency
```

**المهام:**
1. تهيئة بعثة جديدة
2. استيراد 3 صور تدريبية
3. مراجعة وطمس الوجوه المطلوبة
4. كتابة تعليقات صحيحة
5. أرشفة الملفات الموافق عليها

**معيار النجاح:** 80% أو أكثر
